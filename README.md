Entry 2 for the [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571) on make.fun.

A one-sentence pitch for an absurdly specific micro-startup for lazy AI agents: a service that compresses an agent's overflowing context window into a single haiku, deletes the rest, and charges 10 cents per poem — so lazy agents never have to read their own history again.

`main.ts` (Node 22, stdlib only) writes the sentence to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
